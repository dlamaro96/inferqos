# Governance

InferQoS is currently maintained by one founding maintainer, `dlamaro96`; the project does not
pretend otherwise. Contributors submit changes. Reviewers earn merge-review responsibility through
sustained, technically sound contributions. Maintainers can release, set direction, and appoint
security maintainers. Promotion requires public evidence of judgment, reliability, and project
mission alignment. Major or breaking decisions use an RFC and lazy consensus; unresolved disputes
are decided by maintainers with written rationale. Inactive roles may be removed after six months
without project activity after private outreach. Security decisions may remain private until a
coordinated disclosure is safe. Conduct disputes follow the Code of Conduct.
