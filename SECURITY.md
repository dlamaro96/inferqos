# Security policy

The latest minor release receives security fixes. Do not open a public issue for a vulnerability.
Use GitHub’s **Report a vulnerability** private advisory flow and include affected versions, impact,
reproduction, and suggested mitigation. The maintainer aims to acknowledge credible reports within
three business days, provide an initial assessment within seven, and coordinate disclosure after a
fix is available. These are response goals, not a contractual SLA. No security email address is
published because no dedicated monitored mailbox exists.
